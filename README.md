## 🚀 Deployment & Local Setup

### Running Locally
This portfolio is built with pure, modern vanilla web standards (zero bloated build steps, instant load, sub-millisecond execution).

```bash
# Clone the repository
git clone https://github.com/tarunbjoseph/tarun-joseph-portfolio.git

# Navigate to the folder
cd tarun-joseph-portfolio

# Start a local static server
python -m http.server 8080
# Or using Node.js
# npx serve .
```

Then open [http://localhost:8080](http://localhost:8080) in your browser.

### Deploying to GitHub Pages
1. Create a repository named `tarunbjoseph.github.io` or `portfolio` on GitHub.
2. Push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: initial release of executive AI portfolio"
   git branch -M main
   git remote add origin https://github.com/tarunbjoseph/<repo-name>.git
   git push -u origin main
   ```
3. In your GitHub repository settings, navigate to **Pages** > **Build and deployment** > Source: **Deploy from a branch** (`main` / `root`).
4. Your site will be live instantly!
